# 📈 Stock Note

株初心者でも「資産管理・株価確認・投資の学習」を
ひとつのアプリで分かりやすく行えることを目指して制作したWebアプリです。

---

## 💡 開発のきっかけ

アルバイト先の社長が株式投資をしており、
株価や保有銘柄などの情報を確認する際に
「情報が多く、必要な情報を把握しづらい」という話を聞いたことが、
このアプリを制作するきっかけになりました。

実際に私自身も既存の株式・投資関連サービスを見てみたところ、
株式投資の経験がない人にとっては、

- 数字や専門用語が多い
- 何の数字を見ればよいのか分かりにくい
- 株価・損益・為替などの情報が難しく感じる
- 分からない用語を別のサイトで調べる必要がある

と感じました。

そこで、

**「株を知らない人が見ても、何を表しているのか理解できるアプリを作りたい」**

と考え、Stock Noteを開発しました。

単に株価を表示するだけではなく、
「資産を見る」「銘柄を調べる」「損益を確認する」「株について学ぶ」
という一連の流れを、ひとつのWebアプリで行えることを目指しています。

---

## 🎯 制作目的

Stock Noteでは、特に次の3点を重視しています。

1. **初心者でも理解しやすいこと**
   - 専門用語だけを表示せず、意味や考え方も確認できるようにする

2. **必要な情報をひとつのアプリにまとめること**
   - 株価、保有株、損益、チャート、ニュース、為替、学習機能を集約する

3. **情報量が多すぎないUIにすること**
   - カード形式やグラフを活用し、重要な情報を直感的に把握できるようにする

## 🔌 外部API

株価・銘柄検索・株価チャート・ニュース・為替情報の取得には
**Alpha Vantage API**を利用しています。

APIから取得したデータをJavaScriptで処理し、
Stock Noteの各画面へ表示しています。

APIキーはGitHub上のソースコードに直接記述せず、
アプリ内の設定画面から入力し、
ブラウザ側に保存する仕組みにしています。

## 💡 開発で工夫した点

### 1. 初心者視点で情報を整理

Stock Noteで特に意識したのは、

**「株式投資を知らない人が初めて画面を見ても理解できるか」**

という点です。

数字を並べるだけではなく、
グラフ・カード・図解・具体例などを使用し、
情報を視覚的に理解しやすくしました。

また、分からない専門用語を調べるために
別のサイトへ移動する負担を減らすため、
アプリ内に学習機能を設けています。

### 2. 資産管理と学習を一体化

一般的な資産管理機能だけではなく、

**見る → 分からない → 学ぶ → もう一度確認する**

という流れをひとつのアプリ内で完結できるようにしました。

これにより、株価や指標を単なる数字として見るのではなく、
意味を理解しながら利用できることを目指しています。

### 3. API無料枠を考慮した設計

APIを単純に毎回呼び出すのではなく、
**Alpha Vantageの無料利用枠を考慮してAPI通信を管理**しています。

同じデータを短時間に何度も取得しないよう、
取得したデータをブラウザにキャッシュしています。

#### キャッシュ時間

| データ | キャッシュ時間 |
|---|---:|
| 銘柄検索 | 12時間 |
| 株価 | 30分 |
| 日足データ | 6時間 |
| 日中チャート | 30分 |
| ニュース | 2時間 |
| 為替 | 1時間 |

さらに、

- アプリ起動時に不要なAPI通信を行わない
- 必要なデータは「更新」操作で取得
- ブラウザ内でその日のAPI使用回数の目安を管理
- API利用上限に達した場合は保存済みデータを活用

といった処理を実装しました。

単にAPIを利用するだけではなく、
**APIの制約を考慮しながらアプリ全体の通信方法を設計した点**
が技術面で工夫した部分です。

### 4. APIキーをソースコードに含めない

GitHubでPublic公開することを想定し、
Alpha VantageのAPIキーをJavaScriptへ直接記述しない設計にしました。

利用者がアプリの設定画面から入力し、
ブラウザのlocalStorageに保存します。

### 5. レスポンシブデザイン

PCだけでなくスマートフォンからも確認できるように、
画面幅に応じてレイアウトが変化するレスポンシブデザインにしています。

金融アプリに多い情報量の多いデザインではなく、
スマートフォンでも必要な情報を確認しやすい構成を意識しました。

## 🔒 データ・セキュリティについて

保有株など利用者が登録したデータは、
ブラウザのlocalStorageに保存します。

現段階では実際の銀行口座・証券口座とは接続していません。

また、本アプリは学習・ポートフォリオを目的として制作したものであり、
特定の金融商品・銘柄への投資を推奨するものではありません。
