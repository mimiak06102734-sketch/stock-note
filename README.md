# 📈 Stock Note

株初心者でも「見て分かる・触って分かる」を目指して制作した、  
**資産管理・株式学習Webアプリ**です。

株価や保有資産を確認するだけでなく、株式投資の基本を学べる機能もまとめています。

スマートフォンではホーム画面に追加することで、PWAとしてアプリのように利用できます。

---

## 💡 開発のきっかけ

アルバイト先の社長が株式投資をしており、株価や保有銘柄などの情報を確認する際に、

> 「情報が多く、必要な情報を把握しづらい」

という話を聞いたことが、このアプリを制作するきっかけになりました。

実際に私自身も既存の株式・投資関連サービスを見てみたところ、  
株式投資の経験がない人にとっては、専門用語や数字、グラフなどの情報量が多く、  
「何を見ればよいのか」が分かりにくいと感じました。

そこで、

**「株を知らない人が見ても、何を表しているのか理解できるアプリを作りたい」**

と考え、Stock Noteを開発しました。

---

## 🎯 制作目的

Stock Noteでは、次の3点を重視しました。

1. **初心者でも理解しやすいこと**
2. **必要な情報を1つのアプリで確認できること**
3. **情報量を増やしすぎず、直感的に操作できること**

単に株価を表示するのではなく、

**「この数字は何を意味しているのか」**

まで理解できるアプリを目指しています。

- 取引履歴

などを確認できます。

## 🔌 API連携

市場データの取得には **Alpha Vantage API** を利用しています。

主に以下のデータを取得します。

- 銘柄検索
- 株価
- 時系列株価データ
- ニュース
- 為替

---

## ⚙️ API無料枠への工夫

APIの無料利用枠を考慮し、不要な通信を減らす仕組みを実装しました。

### キャッシュ

データの種類に応じてキャッシュ時間を変更しています。

| データ | キャッシュ時間 |
|---|---:|
| 銘柄検索 | 12時間 |
| 株価 | 30分 |
| 日中株価 | 30分 |
| 日足データ | 6時間 |
| ニュース | 2時間 |
| 為替 | 1時間 |

### その他の工夫

- API使用回数の目安をブラウザ内で管理
- 同じデータへの不要な再通信を削減
- 更新ボタンを押した場合にデータを再取得
- API制限時にはキャッシュデータを活用

APIを利用するだけでなく、**利用制限を考慮した設計**を意識しました。

## 🔐 APIキーについて

APIキーをソースコードへ直接記述しない設計にしています。

利用者が設定画面から自身のAlpha Vantage APIキーを入力し、ブラウザ側で利用します。

そのため、GitHub上に個人のAPIキーを公開する必要がありません。

投資関連サービスでは青・黒などの色が多く使われていますが、Stock Noteでは、

**ベージュ・ホワイトを中心とした柔らかいデザイン**

を採用しました。

初心者が「投資は難しそう」と感じにくい画面を意識しています。

また、

- 情報をカード単位で整理
- グラフによる可視化
- 下部ナビゲーション
- スマートフォンを意識したレイアウト
- 専門用語の説明
- 学習ページと資産管理を統合

など、機能だけでなく使いやすさも重視しました。
