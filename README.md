# 📈 Stock Note

株初心者でも「資産管理・株価確認・投資の学習」をひとつのアプリで分かりやすく行えることを目指して制作したWebアプリです。

## 🌐 Live Demo

**公開版はこちら：**  
https://stock-note-mimi.netlify.app

PC・スマートフォンの両方からアクセスできます。

### 📱 QRコード

スマートフォンのカメラで読み取ると、公開版Stock Noteを開けます。
![Stock Note QR Code](./stock-note-qr.png)

## 💡 開発のきっかけ

アルバイト先の社長が株式投資をしており、株価や保有銘柄などの情報を確認する際に「情報が多く、必要な情報を把握しづらい」と困っていたことが、このアプリを制作するきっかけになりました。

私自身も既存の株式・投資関連サービスを見てみたところ、株式投資の経験がない人にとっては、数字や専門用語が多く「どこを見ればよいのか」「何を意味しているのか」が分かりにくいと感じました。

そこで、**株を知らない人が見ても理解しやすい株式アプリを作りたい**と考え、Stock Noteを開発しました。

## 起動
VS Codeでこのフォルダを開き、`index.html`を Live Server で起動してください。

## API設定
1. 右上の ⚙ を開く
2. Alpha Vantage API Key を入力
3. 無料プランでは「米国株のリアルタイム契約を利用する」はOFFのまま
4. 「保存して接続テスト」を押す

## 25回/日対策
- 同じ検索・株価・チャート・ニュース・為替は一定時間キャッシュします。
- アプリ起動時に為替やニュースを自動取得しません。
- ニュース、株価、為替は「更新」を押した時に新しい通信を行います。
- 設定画面に「本日のAPI使用目安」を表示します。
- 25回に達したとアプリが判断した場合、保存済みデータがあればそちらを表示します。
- この回数はこのブラウザが数えた目安で、Alpha Vantage公式の残回数そのものではありません。

## キャッシュ時間
- 銘柄検索: 12時間
- 株価: 30分
- 日足: 6時間
- 日中チャート: 30分
- ニュース: 2時間
- 為替: 1時間

APIキーはGitHubへ直接書き込まず、アプリ内設定から保存してください。


## 学習コンテンツ
「学ぶ」タブを初心者向けに拡充しています。
- 株式の仕組みを図解
- 値上がり益・配当金・株主優待
- 株価が動く主な要因
- PER / PBR / ROE / 配当利回り
- ローソク足の基本
- 長期・積立・分散の考え方
- NISAの基本
- 用語辞典
- 金融庁・JPX・日本証券業協会など公式サイトへの外部リンク

学習ページは投資判断を促すものではなく、初心者が株式投資の基本用語や仕組みを理解するための学習用途です。


## 📲 PWA対応

NetlifyでHTTPS配信し、`manifest.webmanifest` と `service-worker.js` を利用してPWA対応しています。

スマートフォンでは、Safari / Chromeから公開URLを開き、ホーム画面へ追加することでアプリのように起動できます。

- アプリアイコン対応
- standalone表示
- Service Workerによるキャッシュ
- スマートフォンのホーム画面への追加
